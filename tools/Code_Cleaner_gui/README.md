# 코드 정제 도구 (Code Cleaner Tool)

## 개요
이 도구는 복사한 코드에서 줄 시작 부분의 불필요한 숫자(줄 번호)를 제거하고, 원본 들여쓰기를 유지하여 코드를 깔끔하게 정제해 줍니다. 특히 웹사이트나 문서에서 코드를 복사할 때 발생하는 서식 문제를 해결하는 데 유용합니다.

## 주요 기능
- **줄 번호 제거**: `1 `, `2 `와 같이 줄 시작 부분의 숫자와 그 뒤의 단일 공백을 제거합니다. 코드가 없는 빈 줄(예: `2`, `   7`)의 줄 번호는 완전히 제거하여 빈 줄로 만듭니다.
- **원본 들여쓰기 유지**: 코드의 원래 들여쓰기(공백 또는 탭)를 변경하지 않고 그대로 유지합니다.
- **직관적인 GUI**: 입력창, 출력창, 그리고 필요한 기능을 위한 버튼으로 구성된 사용자 친화적인 인터페이스를 제공합니다.
- **클립보드 복사**: 정제된 코드를 한 번의 클릭으로 클립보드에 복사할 수 있습니다.

## 사용 방법
1.  `code_cleaner_gui.exe` 파일을 실행합니다.
2.  **'원본 코드 (여기에 붙여넣으세요)'** 섹션에 정제하고 싶은 코드를 붙여넣습니다.
3.  **'코드 정제'** 버튼을 클릭합니다.
4.  정제된 코드가 **'정제된 코드'** 섹션에 표시됩니다.
5.  정제된 코드를 사용하려면 **'결과 복사'** 버튼을 클릭하여 클립보드에 복사한 후 원하는 곳에 붙여넣으세요.
6.  프로그램을 종료하려면 **'종료'** 버튼을 클릭합니다.
